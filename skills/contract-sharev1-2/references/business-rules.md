# 合同内部分享业务规则

## 分享边界与效果

分享对象是本租户员工；接收人登录相应账号后访问普通合同详情。外部协商邀请使用不同的身份和协商权限协议，不属于本 Skill。未确认存在将完整合同详情生成外部只读链接的能力，不能虚构链接。

分享授予独立访问授权，而不是可配置内容范围的“纯只读包”：

| 内容或动作 | 规则 |
|---|---|
| 表单 | 按正常详情实际可见内容展示，原有表单显示条件仍适用；没有分享专属的字段选择功能 |
| 正文与附件 | 可预览正常详情中存在的正文、合同附件和其他附件；没有正文时不补造正文 |
| 审批与评论 | 有对应数据时可查看；部分历史导入合同可能只展示评论；有合同访问权限时普通评论能力可能允许添加评论 |
| 普通下载与打印 | 没有分享专属禁止项，仍按实际系统配置和业务权限判断；可能只提供 PDF |
| 归档扫描件下载 | 另有归档主文件、归档附件下载等角色权限 |
| 修改、编辑、审批、盖章 | 分享本身不授予这些操作身份；已有其他权限是否允许由相应业务能力判断 |

执行分享不等于获准下载、打印、评论、编辑或发送合同文件。只说明这些授权效果，不顺带执行这些动作。

## 创建分享的权限

| 条件 | 判定 |
|---|---|
| 无分享功能权限 | 禁止创建 |
| 仅“分享我的合同” | 使用系统 owner 判断，可能包含合同负责人、合同需求人、同合同组负责人等；不按申请人名称自行推断 |
| “分享全部合同” | 仍需有目标合同的数据访问权限，不等于租户全部合同 |
| 只有被分享取得的权限 | 需要“分享全部合同”功能权限；仅“分享我的合同”不能替代 owner 条件。企业开启分享权限控制时还需允许再次分享 |
| 同时有非分享权限 | owner、流程关系、抄送、非分享独立授权及其他数据权限等由系统综合计算，不能因有过分享记录就一律当成“仅靠分享” |
| 企业 `enable=false` | 不应用期限、再次分享等附加控制；仍需角色、数据权限和状态允许 |

“可分享”返回 0 表示不可分享，1 表示员工所属部门，2 表示所有部门。它是权限预检查，不替代提交时校验或合同状态判断。部门再分享限制的服务端创建校验存在缺口，收到部门限制或用户要求强制部门范围时，必须按接口准入条件停止受影响动作，不能承诺由当前选人界面保障。

## 状态

以真实枚举及系统判定为准。已核实的普通合同状态：

| 状态码 | 含义 | 状态这一关 |
|---|---|---|
| 0 | 草稿编辑 | 不允许 |
| 1 | 普通作废 | 允许 |
| 2 | 已撤回 | 允许 |
| 3、4、5 | 审批中、已拒绝、审批通过 | 允许 |
| 6、7、12、13 | 签订中、已签订、我方／对方已签 | 允许 |
| 8、9 | 归档中、已归档 | 允许 |
| 10、11 | 变更中、已变更 | 允许 |
| 16、17 | 终止中、已终止 | 允许 |
| 19 | 审批流程被干预中止 | 不允许 |
| 20、21、22 | 预审中、预审成功、预审失败 | 不允许 |
| 23 | 已完成 | 允许 |

后端实现范围为状态码 1 至 17 或 23，但其中预留码不具有已核实业务含义，不能据数值自行放行。协商、模拟、提交和新建等非支持阶段不纳入普通合同分享。未知状态保留原值并停止写入，不能从相似展示文字猜测。两种“已作废”必须区分普通作废与流程干预中止。

## 有效期、重复分享与失效

- `enable=true` 且 `durationSwitch=true` 时，截止日期必填。`shareDurationType` 的 3、6、12 表示最长月数，从本次分享时计算，不固定为 90／180／365 天。截止日按业务时区到 23:59:59；月份末日、闰日和跨时区有歧义时核实当前能力，不能猜值后写入。
- 当天可以作为截止日，只要当天 23:59:59 尚未过去；对过去日期须解释授权已过期的影响并澄清意图，不能无提示按正常有效分享提交。
- 未开启期限控制时，正常分享流程不要求截止日期，创建无到期授权。不能把 `enable=false` 解释为关闭分享功能。
- 每次对同一员工分享同一合同都会新建记录和授权，不覆盖旧期限，不因已有记录自动跳过。用户可能有意续加授权，不能自行去重业务记录。
- 再次分享按本次配置决定期限，可以晚于上游授权。创建当时必须仍具备有效合同权限；原授权已失效且没有其他权限时不能继续转分享。
- 原授权取消或到期，不自动使下游转分享失效。每条授权按自己的期限和取消情况生效。

## 记录管理

有合同管理页面权限且有对应合同访问权限的人可以查看该合同记录，不限于本人发出的记录。存在记录时详情展示分享记录页签。

普通详情取消入口同样要求合同管理页面权限及合同访问权限，不限定原分享人或负责人；每次一条。管理后台按操作日志撤销使用另一权限入口，本 Skill 不调用该入口。

记录页没有直接修改期限操作，调整期限是取消对应旧记录，再创建新分享。启用标志和日期需要结合判断：`enable=false` 说明已停用，但不能仅凭它判断是人工取消还是到期；`enable=true` 也可能等待到期任务更新。不得把无到期记录的 `endTime` 填充值解释为实际过期时间。

## 关联影响

特定补充协议、终止合同、存在后续版本的合同，分享时可能展开到同组其他可分享合同；合同组业务也有专门处理。单个请求资源不保证只新增一份合同的权限。只有已核实全部涉及对象、逐对象权限及用户授权，才可执行；不得以本次接口返回的新增范围反过来补写前确认。

企业同时开启分享控制与自动拉群时，单资源分享可能创建群聊并通知相关人员；否则通常发送分享通知。确认时应说明具体通知／群聊影响，不能为了避免影响擅自修改企业配置。
