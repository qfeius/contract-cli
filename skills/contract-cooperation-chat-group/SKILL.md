# 查询合同协商群 ID

用户提供合同 ID，返回该合同关联协商当前轮次的飞书群 ID、群状态及接口返回的当前用户在群情况。合同已经进入审批，也执行同一查询流程；不以合同阶段或协商已完成为由提前排除。

## 输入与执行上下文

- 必需输入为一份合同的真实合同 ID。沿用同一轮对话已确认的合同；合同编号、协商 ID、轮次 ID、合同组 ID 不能代替合同 ID。仅给名称或编号时，先由已安装的合同搜索能力定位合同；多个候选时由用户选择。
- 通过 `contract-cli` 执行，固定 `--as user`，沿用已确认的环境、租户、profile 和该环境的个人授权。每条请求显式传同一 `--profile <profile>`，不从 profile 名推断目标环境。
- 按[认证技能](../auth/SKILL.md)和[CLI 共享约定](../contract-cli-shared/SKILL.md)复用授权；缺失时按它们的流程恢复。不要求用户提供 Token、Cookie、App Secret 或内部轮次 ID。
- 查看 `contract-cli api call --help`，确认当前正式 CLI 支持 `--channel web`、`--query`、`--header`、`--input-file` 和 `--raw`。缺少命令或依赖时说明具体缺口，不改用历史测试构建或其他调用通道。
- 本 Skill 的完整请求协议见[接口与结果](references/api.md)。不需要安装 Builder 或读取源码，不能依赖作者原聊天中的信息。

## 查询步骤

### 1. 从合同取得关联协商

调用接口参考中的 `briefInfo`，query `contractId` 来自用户已确认的合同 ID。

确认 `data.contractId` 与目标合同一致，读取 `data.cooperationId`、`data.contractNumber`、`data.contractName`，保留原始合同阶段值。ID 原文不变，不经过浮点数转换。

`data` 为空或关联 ID 缺失时，说明未取得可用的合同—协商关联并停止；不能据此断言合同不存在、没有权限或未建群。

### 2. 取得关联协商的当前轮次

使用上一步的非空合同编号作为搜索词；编号为空时使用合同名称。两者均不可用时停止并说明无法可靠定位轮次，不要求用户寻找内部 ID。

调用 `searchV2`，使用当前用户可见协商的全部视图，不添加协商状态或合同阶段筛选。按接口参考翻页，只保留同时满足以下条件的记录：

- `businessId` 与目标合同 ID 原文相同。
- `cooperationId` 与步骤 1 的关联协商 ID 原文相同。

不能按名称相似、列表首项或历史轮次数组顺序选择。列表按协商返回，每项的 `cooperationRoundId` 是该协商的当前轮次。取得精确匹配项后即可结束搜索；相同合同、协商及轮次的重复项可去重，同页出现多个不一致匹配时停止，不擅自挑选。没有匹配时按分页协议继续，达到可访问窗口仍未匹配时说明未能定位，不宣称已查全或没有协商。查询不提供跨页或跨请求的原子快照。

### 3. 查询当前轮次的群绑定

将步骤 2 的真实 `cooperationRoundId` 原文写入请求体 `cooperationRoundIds`，每次只查询一个轮次。调用 `chatGroupStatus`，独立读取返回的群状态、`openChatIds` 和当前用户在群情况。

飞书群 ID 来自 `openChatIds`。`chatGroupIds` 是内部群记录 ID，合同详情或搜索中的 `group_id` 是合同组 ID，均不能当作飞书群 ID。

不调用打开/创建群、加入群或办理协商的操作。该查询无需通过页面协商详情取轮次，不调用 `cooperation/info`，不读取或总结飞书群消息。

## 输出与完成标准

展示合同名称/编号、合同 ID、飞书群 ID、群状态；当前用户在群字段只有实际返回时才展示。排障时可补充协商 ID、轮次 ID 和 trace，不能把它们混称为群 ID。

- 群存在且返回非空 ID：返回该 ID，并按实际状态说明机器人是否在群。
- 未建群：明确当前轮次尚未绑定群，查询到此完成，不自动建群。
- 群已解散：说明已解散；有返回 ID 时标为历史绑定 ID，不承诺群可用。
- 状态未知、返回不完整或字段矛盾：保留已返回的事实，说明无法确认的部分；空 ID 不等同于未建群。

状态映射、缺失数组与失败处理统一按[接口与结果](references/api.md)执行。仅在同一用户上下文成功取得目标关联与当前轮次，并收到该轮次的业务成功响应后，才能报告这次群查询完成。

接口未注册、授权失效、无权限、业务错误或关联变化时，报告实际阻塞步骤。权限失败立即停止；不切换 app、账号、环境或其他接口绕过，不叠加自动重试。需要恢复授权时沿用认证技能的流程。
