# 交接资源类型与 ID 选择

businessTypeCode 是业务类型，不是合同状态、页面 tab 或权限码。发送整数，并从本次同一对象的详情 data.businessTypeCode 原样取得；不得通过更换类型码来选择处理器、绕过权限或改变角色。

## 当前交接入口如何选

| 详情类型 | 业务含义 | businessId / parentId | 本 Skill 处理 |
|---|---|---|---|
| 0，且 assemblyId 明确为 null/0 | 独立合同申请 | contractId / 该详情 groupId | 按主流程核对权限、状态、接收人与关联影响后构造入口 |
| 0，且 assemblyId 为有效父组 ID | 模板批量合同的成员 | 先定位父组，不直接用该成员构造写入 | 读取父组与全部成员，再判断组场景；不可仅因 code=0 当独立合同 |
| 10 | 合同组申请（父组） | contractAssemblyId / 父组详情 groupId | 按合同组参考满足完整范围与权限条件后处理，不套普通合同角色规则 |
| 11 | 合同组下主合同（成员） | 先根据 assemblyId 定位父组 | 不直接提交 code=11；读取父组真实 ID 与类型，不机械改成 10 |
| 17 | 批量合同申请／模板多合同（父组） | contractAssemblyId / 父组详情 groupId | 使用父组真实类型和 ID，核对当前通道权限及完整成员；不能改成 10 绕过类型差异 |
| 其他枚举或未知整数 | 见下表 | 不由名称推导 ID 或类型 | 枚举存在不代表该对象满足本次交接条件；类型或处理条件未明确时停止写入并说明具体缺口 |

普通与父组 ID 均取当前详情，不取搜索外层聚合 ID；parentId 必须取该入口的 groupId。关键字段缺失、对象与类型矛盾或成员关系不明时停止。仅因后端模型容许 parentId 为空或可能纠正错误，也不能省略本流程要求。

## 业务枚举对照

下表是当前核对的业务枚举，供解释详情返回值；**不是可随意传入交接接口的白名单**。真实资源、角色、状态、后端处理路径以及本次完整预检必须同时满足。枚举以后扩展时不猜新码含义。

| 0 | 合同申请 |
| 1 | 合同续签 |
| 2 | 补充协议 |
| 3 | 合同终止 |
| 4 | 评论 |

| 6 | 合同范本 |
| 7 | 合同协商 |
| 8 | 模拟合同申请 |
| 9 | 历史合同导入 |
| 10 | 合同组申请 |
| 11 | 合同组下的主合同 |
| 12 | 修改合同表单 |
| 13 | 合同原始信息 |
| 14 | 合同到期 |
| 15 | 合同作废 |
| 16 | 定制补充协议（超级猩猩） |
| 17 | 批量合同申请／模板多合同 |
| 18 | 模板实例 |
| 19 | 合同重新出具 |
| 20 | 表单模板 |
| 21 | 外部消息协商 |

例如 businessTypeCode=1 表示合同续签，而 contractStatusCode=1 是状态码；两者不可混用。权限码 manage_contract_handover_personal/all、searchTabCode=0/1 也属于独立字段，不用于填写 businessTypeCode。

## 后端路由不等于执行资格

后端按 10/17 进入父组交接路径；11 不进入普通合同路径，本 Skill 不直接提交成员。其他类型即使进入普通分支，还会读取实际有效合同实体、关联组、当前角色及状态，不能根据枚举表把评论、模板或未知类型构造成合同请求。业务类型应与真实对象一致，而非尝试所有枚举寻找能成功的值。

未能确认的类型只能说明“缺少该场景的可执行依据”，不能把它描述为后端永远不支持。用户只要求查询时可展示真实返回的类型及已知含义，不因此新增写操作。
