# 当前身份、操作资格与查询边界

本包读取生成原生页面入口及按需回查所需的最少信息。认证成功、查询命中、拥有链接，都不等于可以提交。身份、对象及轮次始终绑定本次环境；不为消除拒绝切换账号、租户或授权方式。

## 查询的授权范围

具体参数、响应位置、分页与严格模式要求只维护在[查询协议](query-protocol.md)和[发现协议](discovery.md)。按需选用，不能为每个链接无差别调用全部接口。

| 已有查询能力 | 可用结论及边界 |
| --- | --- |
| 当前员工信息 | 核对本次 USER 的实际 tenant 和 employee；用户输入的姓名或员工 ID 不能替换调用者 |
| 本人草稿列表，tab 2/3 | 当前用户本人负责的编辑中单合同/父组草稿；不是全部可见合同，也不是全部可提交业务 |
| MY 协商搜索 | 当前授权人员的参与范围，可含历史轮或跨租户关联；命中不等于当前轮成员、发起者或合同负责人 |
| 严格 MCP 协商详情 | 按查询协议显式启用严格 profile，只采用 ALLOW 返回的当前轮、业务关联和文件等事实；DENY、UNKNOWN、跨租户限制、异常或协议不可用均不能回退 legacy |
| checkCooperation | 仅在查询协议要求且已有真实当前文件时，补当前轮创建者的 tenant+employee 及部分检查结果；不把 OK、hasReadFile 或创建者信息当作完整完成/提交授权 |
| 合同 briefInfo | 当前 USER 获权合同的基础状态和负责人；data=null 可能是无有效协商关联，不证明合同不存在；不保证返回父组关系或页面全部配置 |
| 本人 TODO 列表与 task/info | 按查询协议取得当前待办候选并核对象、任务状态和实际处理人；CURRENT_TODO只支持当前任务承载入口，不等于已核完整重提资格；合同编号不是任务 ID，历史待办不是当前可重提任务 |
| 已核系统草稿路由配置 | 仅按查询协议取得普通草稿选择器确需的 isOneStepTemplate；不能替代对象实际二合一值，也不用于协商完成态分流 |
| 完成态页面配置 | 仅按[查询协议第8节](query-protocol.md#8-协商完成后的页面配置查询)对用户请求办理的独立合同，先证当前轮创建者/有效成员及首次owner或当前任务资格，再按原页面取对象模式；含浏览附带行为，不当作纯读或任意详情兜底 |

首次取数也必须符合当前用户范围。先读租户全量再本地过滤、先读无对象权限接口再补鉴权，均不属于本包可用方案。已有可靠、同范围的新鲜结果可复用；不因缺一个字段反复读取完整详情。

## 操作文字的明确条件

以下条件用于选择聊天中的文字链接；原页面仍执行最新权限、必填和业务校验。

| 拟展示的操作 | 必须具有的当前证据 | 不能替代的证据 |
| --- | --- | --- |
| 独立草稿首次“提交审批” | 当前本人草稿列表新鲜命中且对象、类型、页面分流已确定；或获权快照明确该合同处于首次待提交阶段、当前 owner 与本次 tenant+employee 一致，且实际编辑入口已确定 | 仅可读、字段 WRITE、历史申请人、最初创建人、列表无拒绝、负责人字段缺失 |
| 父组草稿“提交审批（整组）” | 新鲜本人父组草稿或等价获权父组上下文，明确父组 ID、10/17 类型、状态、当前负责人范围和对应组页面 | 仅有成员可读权、只读成员协商、成员ID、类型0或数量大于1 |
| 协商页的待发起/完成态提交入口 | 同对象、同当前轮；当前用户为本轮创建者且处于有效参与编辑态；实际页面分支已确定；首次审批继续满足 owner 条件，重提继续满足当前任务条件 | 合同 owner 不能替代本轮发起者；本轮发起者不能替代合同 owner；页面按钮存在不能替代最终提交权限 |
| “去完成协商” | 当前轮状态2，当前 tenant+employee 与本轮创建者一致，且当前可靠快照明确可完成；仍由用户操作页面完成确认、文件与表单校验 | 已确认、已定稿、确认流程完成、全局 EDIT、部分检查 OK 都不能单独推导此人可完成 |
| “重新提交审批” | 合同当前为审批撤回/拒绝，有仍有效且属于本对象的重提/修改申请待办，当前用户是该任务实际处理人，并有本轮已有可信的修改/重提动作快照及实际入口依据；仅查到CURRENT_TODO时标“打开当前任务” | 历史审批人、第一条任务、抄送、仅 writePermission 或过期 todoTaskId |
| “去重新协商” | 当前轮状态7，已有对当前用户生效的 canRestartAfterReject=true | 不是仅限发起者，也不能由发起者、经办人或角色名称自行推出 true |

首次提交前 `submitterEmployee` 可以为空，不能因它为空拒绝有效 owner 的草稿入口。非 owner 的首次申请不标成已确认可提交；若存在另一个真实任务办理权限，按重提/流程任务单独判断，不用该任务覆盖首次提交规则。后台非 owner 配置、页面兼容默认值均不作为本包独立授权证据。

正文锁定或正文只读，不等于整个协商页面只读，也不等于不能完成协商或进入审批。确认人、定稿人、法务、经办人、表单填写人拥有的具体操作应按各自权限解释，不能互相替代。

## 当前轮与身份如何衔接

1. 保留每次结果的对象 ID、当前轮 ID、取得时间和来源。轮次或业务关联变化时，旧创建者、文件和操作资格失效，重新取当前事实，不能拼接新旧轮次。
2. MY 搜索的 `isCooperationUser` **明确为 true 且属于同一当前轮**，才可作为本轮有效成员事实，支持该页面全局参与编辑态的判断；搜索命中、缺省 userType、confirmableStatus 均不能替代。全局参与编辑态仍不等于正文可编辑或有提交权。
3. 本轮创建者使用当前轮事实。严格详情的创建者身份投影和 checkCooperation 的 tenant+employee 按[查询协议](query-protocol.md)核对；不能拿 MY 最初创建人、同名人员或缺租户的人员字段直接判本轮发起者。
4. 当前 `todoTaskId` 只作任务候选；按查询协议核对后，才可按页面映射用作 `processTaskInstanceId`。来源仍保持真实入口，不能因有任务 ID 就把协商列表伪装成任务来源。
5. 请求失败、授权 UNKNOWN、字段缺失或版本冲突分别保留为未确认；不写“未发现禁止，所以允许”，也不把未确认写成“用户无权限”。已获权的协商承载页仍可按[系统页面入口](native-page-handoff.md)交付。

## 不用于本包补读的入口

- 完整 `cooperation/info` 可能加入当前轮、改变确认流程、写已读及访问记录；唯一受限用法是[查询协议第8节](query-protocol.md#8-协商完成后的页面配置查询)的完成态模式查询。未满足其授权和前置条件时不调用，不预开编辑器、不把它用于一般列表刷新。用户主动打开协商链接时，对相关行简短说明系统可能记录已读、符合历史参与条件的用户可能加入当前轮。
- 完整 `contract/info`、`contractAssembly/info`、`childrenInfo` 及 composition 可能间接修正并保存合同/交易方历史数据，不作为本包只读兜底。
- 返回二合一原始数据但未适配当前 USER 对象权限的接口，不用于补配置；当前租户开关不替代对象实际二合一值。
- 不调用 permission/business/list 补重提能力；当前任务查询只证明任务承载入口，不能用另一个权限响应补成未经核实的完整重提协议。
- 不通过保存、预演、生成正文、提交校验/准备、跳过/完成/重启协商或 task/run 来探测可提交性；不调用会执行页面等价加入/已读的其他 Skill 全流程补读。

这些边界不构成新增系统研发任务。现有安全能力不足时，给已有证据支持的原生页面或具体无法定位原因，其他对象继续处理。

## APP 与浏览器

本包没有可用于 APP 的安全对象查询协议，不以结构化 get、通用 search 或 USER-only web 请求代查，也不把应用可读合同说成“你的草稿”或个人可提交。仅有 APP 上下文时，只能复用本轮已有可信获权快照及已核站点给查看入口；缺少该事实则说明当前无法代查定位，不切 USER、不安排系统改造。

浏览器使用自己的登录会话，不与 CLI 自动共享。链接不携带 Token、Cookie、shareCode、伪造 userId/appId 或租户身份。最终页面拒绝、对象不可见、状态变化、任务过期与读取失败分别报告；本包不修改权限、不替他人确认定稿、不代发消息或审批。
