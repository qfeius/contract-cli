# AI 变更记录：合同摘要查询生成中状态展示

## 2026-10-15 生成中仅展示状态

- 改动内容：`contract summary query` 返回成功且 `data.status=1` 时，输出只保留响应结果和状态，不展示可能残留的摘要及其他 `data` 字段；普通输出和 `--raw` 均适用。`status=2` 的完整摘要输出不变。
- 影响范围：摘要查询命令输出、帮助、命令参考、智书摘要 Skill 与验收规则。
- 关键决策：沿用现有开放平台请求和渲染调用链，仅在摘要查询的成功响应上做命令专属过滤；业务失败响应保留原文，不自动轮询或重试。
- 验证结果：先新增普通输出和 `--raw` 的回归测试，确认旧实现泄露生成中响应里的旧摘要字段；实现后定向测试与 `make release-check` 均通过，后者覆盖完整 Go 测试、Node 测试、CLI 冒烟和本地打包校验。

## 2026-10-15 生成中提示语

- 改动内容：生成中的输出将 `msg` 统一为“摘要正在生成中，请稍后再试”，保留 `data.status=1`，继续隐藏摘要内容；普通输出和 `--raw` 一致。
- 验证结果：先修改两种输出模式的提示语断言并确认失败，再实现响应过滤；定向测试通过。

## 2026-10-15 当前版本维持单次查询

- 用户明确将“等待生成完成后再返回”留到后续版本；当前 `status=1` 立即返回提示，不自动等待或轮询。
- 在普通输出和 `--raw` 的生成中测试中检查只发起一次查询；定向测试通过。
