# 授权码登录每次重新注册客户端

## 需求

- `auth login` 发起授权码授权时，每次注册新的客户端，不复用已保存的 `client_id`。
- 设备授权方式不变。

## 修改

- 移除用户授权码登录中仅在 `ClientID` 为空时注册的条件，沿用原有客户端注册调用链及注册参数。
- 授权链接及授权码换取令牌均使用本次注册返回的客户端 ID；登录成功后沿用原有配置保存流程。
- 注册失败直接返回错误，不使用旧客户端 ID 继续授权。
- 当前仓库未发现设备授权实现；生产代码改动仅涉及 `userAuthProvider.Login`，机器人授权未修改。

## 测试

- 先编写回归测试，确认旧实现会复用已有客户端 ID，且首次登录后第二次登录也不会重新注册。
- 覆盖空客户端 ID、已有客户端 ID、连续两次登录，以及自动打开浏览器和仅输出授权链接两种入口。
- 验证授权链接、令牌交换和登录后的配置均使用当次注册的 ID；注册失败不会进入授权，也不会修改原有凭据。
- 更新仅输出授权链接的既有测试，验证等待回调前输出包含新客户端 ID 的链接。
- 修改后授权码登录回归测试、`go test ./...`、`go vet ./...` 和 `git diff --check` 均通过。
