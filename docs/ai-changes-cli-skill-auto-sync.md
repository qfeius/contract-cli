## 2026-10-09：最终收口决策

- 已确认：全局 CLI 安装或升级只自动同步已有登记且可验证的 Skill 目录；首次安装、登记丢失或历史自定义目录未识别时，不把 Codex、WorkBuddy、豆包候选目录当作真实目标直接写入。

- 豆包按用户 Skill 目录 `.user_skills` 处理；客户端系统管理目录 `.skills` 继续拒绝写入。确认真实用户目录后执行完整安装，成功后登记，后续全局升级自动同步。
