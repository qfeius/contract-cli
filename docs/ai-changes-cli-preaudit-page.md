## 恢复与兼容边界

- CLM 创建沿用已提供的 `request_id` 幂等契约；已知 taskId 只查询原任务。
- 未知启动结果且没有 taskId 时停止核实，不自动重发；本轮不实现 AI 启动响应丢失后的自动恢复。
- 上传或引用响应未知时不自动重传。明确失败后，只有用户明确要求再次发起才使用原预审重新执行 start。
- 不新增预检查、预校验、身份上下文接口，不自动打开页面，不改前后端接口、数据库、计费或上线安排。
- 本地记录无自动过期和后台清理，由用户管理；回滚 CLI 时保留已有预审、任务和记录，避免重复发起。
