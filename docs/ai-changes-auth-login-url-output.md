# 授权链接输出时机修复

## 需求与原因

- 默认授权码登录在授权成功后才显示授权链接，输出顺序与用户操作流程不符。
- 原实现仅在 `--no-open-browser` 模式下提前输出链接；默认模式将链接拼入登录成功后的返回消息。

## 修改

- 授权链接生成后立即输出，然后按选项打开浏览器并等待授权回调。
- 浏览器打开失败时，用户已能看到链接并手动完成授权。
- 登录成功后仅返回成功提示及令牌到期时间，不重复输出授权链接。
- 沿用现有输出接口与授权调用链，保留每次登录重新注册客户端的行为。

## 验证

- 先添加回归测试，确认旧实现中浏览器打开成功和失败两种场景均因链接尚未输出而失败。
- 修改后验证浏览器打开成功、打开失败以及不自动打开浏览器三种场景。
- 检查链接在打开浏览器及等待回调前已输出、早于完成日志且只输出一次；成功消息保留到期时间且不重复链接。
- 授权码登录相关测试、`go test ./...`、`go vet ./...`、`git diff --check` 均通过。
