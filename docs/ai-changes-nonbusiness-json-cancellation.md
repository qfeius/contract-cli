- 修复 MR !30 review 发现的取消后仍输出成功 JSON、版本命令退出 0，以及响应完成后继续保存配置或 Token 的问题；统一在 `codex/dev-trace-verification` 实现后同步测试集成分支。
- 先加入实际失败的完成日志/有效响应取消回归，再加入安全提交实绩与最终 stdout writer gate；版本及别名统一退出 130，旧 update `--json` 与默认文本格式保留。
- 配置清理、保存及手动/自动更新缓存写入前检查取消；部分清理或保存已完成时用 `details.state=committed/operation/result` 报告安全实绩，保留原错误链及已有 Skill 详情。
- App 凭据改为 exchange 结束且确认未取消后落盘；普通失败仍保存输入凭据。Secret 已写入时完成配套 Profile 保存，晚到取消不额外切默认身份。必要时序变化为 Secret 存储失败在一次 exchange 后发现。

- 回归涵盖原 6 个缺陷、各版本别名/两种格式、缓存新旧状态、配置部分清理、App 提交前后、Device 清理、编码/实际输出边界及 Skill 实绩保留；补充旧调用方 overlay 回放红例，审查树和真实用户数据不受测试影响。
- 未增加显式锁、重试或补偿，保留既有 Device 操作锁范围和次序；协作取消无法撤回已经开始写出的 stdout 字节，脚本仍需同时检查退出码和 stderr。
