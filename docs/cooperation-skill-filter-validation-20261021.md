## 关键发现

1. 完成搜索分组 4 映射原始返回状态 3/6，均按页面展示“协商完成”。
2. “我是否可确认 → 待我确认”页面 4 条，顶部“待我确认/定稿”3 条，不能互相替代。
3. 财务角色筛选的第一条 confirmed_roles 为空，页面同样命中并显示“-”；展示字段不能代替服务端的筛选语义。
4. 第一轮仅根据 createEmployeeIds 数组误判了页面多选；第二轮实际操作确认页面选择器为单选。MCP create_user_id 仍单值，发起人多选尚待扩展。
5. 日期可见性随视图变化：完成时间不在待我确认视图显示；我确认的时间仅在个人全部/已确认视图显示。
